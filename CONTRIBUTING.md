# Contributing to Astro Static Studio

Use GitHub Issues to report bugs and discuss proposed changes. For bug reports, include the affected platform, the steps to reproduce the issue, and the expected and actual behavior. Use sample data when sharing logs or screenshots.

1. Fork the repository and create a topic branch from `main` in your fork.
2. Install dependencies with `npm install` using Node.js 22 or later. Use `npm run dev` to run the Studio locally.
3. Run `npm run check` and `npm test` before submitting changes. For build or packaging changes, also run `npm run build` and describe any platform-specific verification.
4. Open a pull request against `main` with a summary of the change, the checks you ran, and a link to the related issue if there is one.

[@arashashrafii](https://github.com/arashashrafii) coordinates issues, reviews pull requests, and decides which changes to merge into `main`.
